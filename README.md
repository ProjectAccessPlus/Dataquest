🎮 DataQuest: Analytics Challenge
    A lightweight browser‑based mini‑game designed to help users practice analytics concepts in a fun and interactive way.
    This game is free to use, free to edit, and proudly created by Rem.

🕹️ About the Game
    Players enter their name, start the challenge, and track their progress through:
    - XP points
    - Number of questions answered
    - Best streak

The interface is simple, fast, and optimized for quick learning sessions.

✨ Features
    - Clean and intuitive UI
    - Real‑time XP and streak tracking
    - Fully client‑side (no backend required)
    - Mobile‑friendly layout
    - Easy to customize and extend

🛠️ Technologies Used
    Based on the current build (reference: ):
    - HTML5 — page structure
    - CSS3 — styling, layout, responsive design
    - JavaScript (Vanilla JS) — game logic, counters, input handling
    - No frameworks required
    - No server-side code
    - Static hosting compatible (GitHub Pages, Base44, Replit, Netlify, Vercel)

📦 How to Run
    1. Clone or download the repository
    2. Open index.html in any modern browser
    3. Start playing — no installation needed
